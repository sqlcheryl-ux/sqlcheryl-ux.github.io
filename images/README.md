# images/

This folder holds the photos shown on the gallery page.

- Drop image files here (JPG or PNG, simple filenames with no spaces, e.g. `lake-sunset.jpg`).
- Then add a `<figure>` block for each photo in `../gallery.html` — there's a
  commented example in that file showing the exact format.
- Keep photos web-sized (under ~1 MB each) so the page loads fast.
