Remote into Windows from a Mac with Homebrew

Microsoft's remote desktop client is now called Windows App (free on the Mac App Store). To install it from the terminal instead, open Terminal (Cmd+Space, type Terminal, hit enter) and run: 

brew install --cask windows-app

Not sure you have Homebrew? Check with brew --version. If it's missing, install it first with: 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The old cask name (microsoft-remote-desktop) was retired, so windows-app is the one to use. Open Terminal with Cmd+Space, type the command, hit enter — the app lands in your Applications folder. Then open it and add the Windows machine by name. If you get stuck mid-command with a dquote cmdsubst> prompt, you mistyped a quote: hit Ctrl+C and paste the command in one go instead of typing it.

2026-09-29

Make job-failure emails actually useful

The built-in "notify on failure" email only says the job failed. Add a final job step that runs when the main step fails: have it read the failed step's message from msdb.dbo.sysjobhistory and send it with sp_send_dbmail. Then the alert arrives with the real error attached.

2026-09-29

SSIS errors live in the SSISDB catalog

When a package fails, skip the Agent history and go straight to SSISDB.catalog.event_messages joined to catalog.executions. Filter event_name to OnError / OnTaskFailed — that's the full error chain, including which task raised it.

2026-09-29

Job failure emails are thin — check msdb instead

A dbmail alert tells you which step failed but not why. The actual error text is in the message column of msdb.dbo.sysjobhistory — query it before guessing. Script: scripts/diagnostics/job-failure-detail.sql.
